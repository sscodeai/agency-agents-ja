# Osaurus Integration

Converts all `agency-agents-ja` agents into Agent Skills style `SKILL.md`
directories for Osaurus.

## Install

```bash
./scripts/convert.sh --tool osaurus
./scripts/install.sh --tool osaurus
```

This copies generated skills to `~/.osaurus/skills/`.

## Regenerate

```bash
./scripts/convert.sh --tool osaurus
```
