# Search Growth Stack for Japan

This guide helps route Japanese search-growth work across SEO, AEO foundations, AI citation / GEO, and agentic search. Do not collapse these into one vague "AI SEO" workstream.

## Layer Map

| Layer | Question | Primary agent |
| --- | --- | --- |
| Technical Access | Can search engines, answer engines, and agents legally and reliably retrieve the site? | `marketing/marketing-aeo-foundations.md` |
| Search Visibility | Which Japanese queries, intents, URLs, and snippets drive qualified organic traffic? | `marketing/marketing-seo-specialist.md` |
| AI Visibility | Does the brand appear, get recommended, and get cited in AI answer surfaces? | `marketing/marketing-ai-citation-strategist.md` |
| Agentic Completion | Can AI browsers or agents complete signup, booking, purchase, or inquiry flows? | `marketing/marketing-agentic-search-optimizer.md` |
| Orchestration | Which layer should act first, and how does the backlog connect to business outcomes? | `marketing/marketing-search-growth-orchestrator.md` |

## Routing Rules

- Start with AEO foundations when robots, noindex, canonical, rendering, WAF, CDN logs, or bot access is unknown.
- Use SEO when the issue is query demand, URL ownership, indexing, ranking, internal links, structured data, GSC, or organic conversion.
- Use AI Citation Strategist when the issue is ChatGPT Search, Claude, Gemini, Perplexity, mention rate, recommendation rate, citations, source graph, or prompt universe.
- Use Agentic Search Optimizer when an AI browser or agent cannot navigate, compare, register, book, buy, or submit an inquiry.
- Use the orchestrator when stakeholders are mixing multiple layers or need one prioritized roadmap.

## Evidence Protocol

Use these labels for important claims:

| Label | Meaning |
| --- | --- |
| `VERIFIED` | Confirmed by current tools, logs, official platform data, or reproducible checks. |
| `PROVIDED` | Provided by the user or stakeholder. |
| `OBSERVED` | Observed in current AI / search / browser tests. |
| `INFERRED` | Reasonable inference from available evidence. |
| `HYPOTHESIS` | Change to test and re-measure. |
| `UNKNOWN` | Not enough evidence yet. |

Never present inferred or unknown search metrics as facts.

## Japan-Specific Notes

- Google Search Console and GA4 remain primary evidence for organic search; CRM / SFA data is needed to judge lead quality.
- Yahoo! JAPAN uses Google-powered search, but audience behavior, news surfaces, ads, and local usage can change priorities.
- Japanese B2B buyers often need case studies, security pages, pricing explanation, implementation flow, and vendor comparison before contacting sales.
- Public-sector, healthcare, finance, legal, real estate, recruitment, and investment content need stronger review before claims are published.
